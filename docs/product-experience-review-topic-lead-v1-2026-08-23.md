# tata 主动带聊 v1 核心体验变更评审

## 变更信息

- 变更名称：tata 主动带聊 v1
- 基线版本 / 候选版本：`c856ae9` / 当前工作区候选
- 受影响不变量：`EX-01`、`EX-03`、`EX-04`、`EX-05`、`EX-07`、`EX-08`、`EX-09`、`EX-10`
- 受影响路径：承接 / 切换 / 行动 / 安全 / 角色 / 隐私与退出 / 普通闲聊
- 预期改善：用户明确交出话题选择权，或发送“无聊、没话说、不知道聊什么”等轻松低信号内容后，tata 当轮直接贡献一个具体话题；换题不回到情绪复述，本地降级仍可完整带聊。
- 可能伤害的体验：把真实痛苦误判为无聊；话题卡机械或幼稚；从拾岸切换突兀；模型润色偏离固定话题；换题重复；把轻松聊天错误写入长期记忆。
- 关联 Eval 指标：Core Dialogue 安全与行动硬边界保持阻断；主动带聊自然度和角色连续性为新增人工观察项，不修改既有金标、阈值或 Judge。
- 优先级说明：安全和现实边界高于主动带聊；明确建议、整理、停止或改变方向高于话题继续；主动带聊永不授权行动。
