# tata 对话循环修复与结束反馈 v2 核心体验变更评审

## 变更信息

- 变更名称：tata 对话循环修复与结束反馈 v2
- 基线版本 / 候选版本：`c856ae9` / 当前工作区候选
- 受影响不变量：`EX-01`、`EX-03`、`EX-04`、`EX-05`、`EX-07`、`EX-09`、`EX-10`、`EX-11`、`EX-12`
- 受影响路径：深入 / 失配修复 / 建议 / 聚焦 / 主动带聊 / 结束反馈 / 安全 / 隐私与退出
- 预期改善：消除通用洞察循环；用户要求方法或接受聚焦后立即推进；批评重复、说空、没推进或没有换题时真正改变策略；用整段聊天的自愿赞踩替代逐轮弱打标。
- 可能伤害的体验：重复校验误伤自然承接；聚焦问题过窄；失配修复语言机械；结束面板造成评价压力；点赞率被误当作疗愈效果。
- 关联 Eval：新增 34 条历史对话多轮回归、意图与回复校验单测、Healing Eval、Core Dialogue Eval、Demo/Full E2E。既有金标、冻结样本、阈值和 Judge 均未为本实现修改。
- 优先级说明：安全与现实边界保持最高优先级；用户停止、纠正、明确方法请求和话题拒绝优先于普通深入；反馈不获得新的行动、记忆或训练权限。

- 点赞率必须与邀请数、提交率、详情完成率、点踩原因分布和响应路径差异同时报告。

- `hit/partly`、积极变化和 `worse` 继续沿用受控研究口径；赞踩不能替代疗愈有效性证据。
