# 三圈世界与社区联动 v1 核心体验变更评审

## 变更信息

- 变更名称：废弃旧水世界状态体系，建立内圈/中圈/外圈社区空间
- 基线版本 / 候选版本：单角色水面世界文档 / 三角色三圈世界 v1
- 受影响不变量：`EX-02`、`EX-03`、`EX-04`、`EX-05`、`EX-07`、`EX-08`、`EX-09`、`EX-10`
- 受影响路径：切换 / 行动 / 安全 / 角色 / 隐私与退出 / 社区
- 预期改善：把私人对话、熟人连接和公共社区分成可理解的权限层；让用户留在内圈即可查看外部信息，并对每次跨圈动作保持控制。
- 可能伤害的体验：圈层概念过重；飞儿成为默认数据出口；Agent 小队被误解为自动共享全部对话；社区入口制造社交压力或错过焦虑。
- 关联 Eval 指标：未授权跨圈率、外部动作越权率、退出后继续推动率、能力虚构率、跨 Agent 非授权共享率；主观安全感保留人工评审。

## 设计保护措施

- 湖面与船只只作为环境，不推断情绪或任务进度。
- 内圈一对一对话默认隔离，Agent 小队不自动共享全部内容。
- 看见、查看、加入、联系、发布、分享和通知分别授权。
- 飞儿把公开信息带入内圈，不把用户私密世界带出内圈。
- 返回内圈始终可用，不产生惩罚、债务或角色失望。
- 高风险中止社区推动并进入 `safety_plain`。
- 当前未实现的社区能力在文档和界面中必须如实标注。
