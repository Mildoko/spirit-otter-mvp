# 进入体验默认开启声音评审

## 变更信息

- 变更名称：准入操作同时解锁声音
- 基线版本 / 候选版本：需另外点击“开启声音” / 点击“进入静水区并开启声音”后直接开启
- 受影响不变量：`EX-04`、`EX-09`；非回归 `EX-01`–`EX-03`、`EX-05`–`EX-08`、`EX-10`
- 受影响路径：用户控制 / 能力诚实 / 准入交互 / 声音
- 预期改善：移动浏览器把用户主动的准入点击视为声音授权手势，进入后回复语音、BGM 和互动音效默认全开。
- 可能伤害的体验：用户不知道点击准入会开启声音；错误体验码时声音引擎也被解锁；覆盖用户之前的静音选择。
- 保护措施：按钮明确写出“并开启声音”；只使用产品已有的默认全开配置，不覆盖浏览器中已保存的用户手动选择；进入后仍可一键静音或分项关闭。
