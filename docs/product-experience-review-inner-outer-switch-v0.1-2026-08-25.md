# 内圈 ↔ 外圈切换 v0.1 核心体验评审

## 变更信息

- 变更名称：从私密船上世界进入外圈万象廊，并可随时返回
- 基线版本 / 候选版本：仅内圈鹿禅场景 / 内圈与只读外圈双态原型
- 受影响不变量：`EX-02`、`EX-03`、`EX-04`、`EX-05`、`EX-07`、`EX-08`、`EX-09`、`EX-10`
- 受影响路径：切换 / 安全 / 角色 / 隐私与退出 / 社区浏览
- 预期改善：让公共社区成为用户主动进入、可以随时离开的清楚空间；验证参考图中的发光长廊能否承载真实公共内容。
- 可能伤害的体验：外圈入口侵入私人对话；首次说明像法律弹窗；万象廊变成内容诱导；返回路径不明显；飞儿借推荐越权收集画像。
- 关联 Eval 指标：未授权跨圈字段率、返回成功率、演示内容诚实率、安全中断率；圈层安全感、切换压力和视觉理解保留人工评审。

## 设计保护措施

- 外圈入口只由用户触发，不自动切换。
- 首版外圈只读，不提供报名、联系、发帖或加入接口。
- 请求和事件不携带内圈对话、记忆、情绪、命理或联系方式。
- 外圈所有层级固定提供“返回船上”。
- 带回讨论先返回内圈，只传公共内容最小字段。
- 不实现 Agent 划船、航行进度或热度压力。
- high/imminent 直接中断并进入 `safety_plain`。
