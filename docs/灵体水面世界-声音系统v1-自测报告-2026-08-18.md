# 灵体水面世界：声音系统 v1 自测报告

日期：2026-08-18  
结论：Demo 与 Full 的本地自动化、PostgreSQL 集成和 30 分钟声音稳定性测试均通过；外部模型在线探测和多设备人工听感验收仍属于发布环境项。

## 已实现范围

- 浏览器系统中文语音适配器，以及深潮、拾岸、安全直述三种节奏配置。
- 全局 AudioDirector、明确启声、声音设置持久化、取消、重播和生命周期清理。
- 水面与星空 BGM、视角交叉淡化、语音播放期间的 BGM ducking。
- 场景接近、退场、回复水纹与邀请铃声音效，以及两秒冷却。
- elevated 降低声景，high/imminent 停止 BGM 和装饰音并使用安全语音参数。
- 服务端确定性 AudioCue、Agent 声线注册校验和 `AUDIO_V1` 特性开关。
- Pixabay 临时素材本地打包、来源登记和本地服务音频 MIME。

## 运行时检查

- Demo 页面能够显示“开启声音”，点击后变为“声音已开”。
- 水面、星空和四类音效资源均成功返回；抽样 MP3 响应为 HTTP 200、`audio/mpeg`。
- 设置面板显示总开关、语音/BGM/SFX 分项开关和四个音量滑块。
- 回复出现后具备“重播这条水獭回复”入口。
- 本地页面控制台未出现 warning 或 error。
- 测试期间只有一个 AudioDirector/AudioContext 创建入口；单元测试覆盖替换朗读时取消上一条语音。
- 30 分钟稳定性结束并主动 GC 后，JS 堆内存比起点减少 1,190,584 字节，DOM 节点减少 50；未观察到持续增长。
- 发现并修复 Full E2E 以 `NODE_ENV=test` 构建前端造成的开发构建污染；现改为 production 构建、test 运行，产物主包由约 715KB 降至约 477KB。
- 发现 Full E2E 的接受邀请文本与当前策略不匹配；已统一为确定性的“先写明天汇报的标题”，修复后桌面和移动回归均通过。

## 剩余发布环境项

- Full 预检的外部模型在线探测返回 `provider_error`；本次声音测试使用本地规则回退，不受影响。正式 Full 发布前需在具备有效模型服务与网络的环境重跑预检和模型验收。
- 自动化使用系统语音桩验证朗读参数与生命周期；30 分钟测试验证了引擎稳定性，但不能替代人耳判断。最终发布前仍需在 Windows Edge/Chrome、macOS Safari、iOS Safari 和 Android Chrome 上人工试听实际声线、循环接缝和蓝牙中断恢复。

## 发布建议

- 保持 Full 模式的 `AUDIO_V1=false`。
- Demo 的 30 分钟自动稳定性测试已完成；发布前再进行至少一次有人耳参与的连续试听。
- 正式对外前替换临时 Pixabay 素材，并进行一次商用授权和响度复核。
