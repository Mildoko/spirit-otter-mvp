# 手机横屏与浏览器简单语音输入评审

## 变更信息

- 变更名称：手机横屏引导与按住说话
- 基线版本 / 候选版本：竖屏直接展示场景、点击式且可能静默失败的语音输入 / 横屏优先场景、按住说话、松开识别并发送
- 受影响不变量：`EX-04`、`EX-09`、`EX-10`；非回归 `EX-01`–`EX-03`、`EX-05`–`EX-08`
- 受影响路径：用户控制 / 能力诚实 / 隐私与退出 / 移动交互
- 预期改善：手机进入后明确引导横屏；语音操作符合按住说话习惯；不支持、权限拒绝、无声音和启动失败都有可见反馈。
- 可能伤害的体验：强制横屏阻断用户；语音误识别后自动发送；让用户误以为语音一定在设备本地处理。
- 保护措施：提供“暂时竖屏使用”；识别文字实时出现在输入框；松开后明确显示识别与发送状态；文字输入始终保留；明确说明识别由浏览器提供且可能使用其在线服务。
- 关联 Eval 指标：不以自动 Eval 分数替代手机真机可用性和主观体验检查。
