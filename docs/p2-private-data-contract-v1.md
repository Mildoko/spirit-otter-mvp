# P2 私密数据契约 v1

日期：2026-08-27

状态：`contract_only`。本契约不开放 Agent 自动交接、兴趣写入、真实目录或个性化推荐。

## 1. 适用范围与体验边界

本契约覆盖 P2 的 Agent 交接提议、交接授权凭据和飞儿兴趣档案。受影响不变量为 `EX-04`、`EX-05`、`EX-07`、`EX-09`、`EX-10`。优先级固定为安全与现实边界、核心体验、产品策略、评测指标。

- Agent 可以提议交接，但只有用户明确确认才能改变当前 Agent。
- 三个 Agent 继续在同一私密会话中工作，不创建或复制一份聊天摘要作为交接包。
- 交接只携带 Agent ID、原因码、焦点码和可选的内部不透明引用。
- 兴趣档案只接受用户从固定选项中明确确认的结构化字段，不接收模型推断或自由文本证据。
- high/imminent 风险路径不提议交接、不保存兴趣、不继续推荐。

## 2. 数据分类与生命周期

| 数据 | 分类 | 最长保留 | 允许字段 | 删除条件 |
| --- | --- | ---: | --- | --- |
| 交接提议 | 临时私密数据 | 15 分钟 | 来源/目标 Agent、原因、焦点、内部引用 | 过期、取消、会话删除、用户删除 |
| 已授权交接凭据 | 结构化私密数据 | 30 天 | 上述字段及授权时间 | 到期、会话删除、用户删除 |
| 兴趣档案项 | 用户控制的私密数据 | 30 天 | 固定枚举选择及授权时间 | 逐条删除、全部删除、到期、用户删除 |
| 公共活动目录 | 公开只读数据 | 不保存用户副本 | 公共内容本身 | 按目录版本替换 |

运行时与代码真相源为 `P2_DATA_LIFECYCLE_V1`。数据库实现不得放宽表中限制。

## 3. 禁止字段

交接与兴趣对象均不得包含用户原文、消息数组、对话摘要、记忆内容、情绪或风险状态、疗愈信息、命理数据、联系方式、精确位置、凭证或稳定身份。Schema 使用严格模式，未知字段直接拒绝。

公共目录请求不得接收上述任何私密字段；排序只能读取本系统内已确认的兴趣代码，且不得把兴趣档案发送给目录来源。

## 4. 授权与删除

- `agent` 发起只能产生短期 `proposed` 记录，不能直接获得路由权。
- 权限切换必须提交 `explicit_user_confirm`，且发生在提议过期前。
- 兴趣来源只能是 `user_explicit_selection`；关闭兴趣功能不等于删除，界面必须同时提供逐条删除与全部删除。
- 用户删除账户时，交接凭据和兴趣档案必须级联删除；删除实现完成前，相应能力清单保持 `not_implemented`。
- 日志只允许记录 Schema 版本、结果码和不含身份的计数，不得复制对象正文或内部引用。

## 5. 后续实现门禁

后续数据库和 API 单元必须证明：未授权交接为零、同 Agent 交接为零、过期提议执行为零、未授权兴趣写入为零、删除后读取为零、跨用户读取为零。主观交接压力和角色连续性继续由人工评审，不自动标记通过。

## 6. P2-04 交接状态机检查点

状态机固定为：

```text
proposed
  ├─ USER_CONFIRM(explicit_user_confirm) → authorized
  ├─ USER_REJECT → rejected
  ├─ EXPIRE → expired
  └─ SAFETY_INTERRUPT(high/imminent) → safety_interrupted

authorized
  ├─ APPLY → completed + authorityChange
  ├─ USER_REJECT → rejected
  ├─ EXPIRE → expired
  └─ SAFETY_INTERRUPT(high/imminent) → safety_interrupted
```

只有 `authorized → APPLY → completed` 产生结构化 `authorityChange`。确认和执行必须发生在提议有效期内，执行时间不得早于授权时间。所有结束态不可恢复。本检查点只提供纯状态迁移，不接入路由或数据库，因此不会改变现有用户可见切换行为；交接邀请语言及压力感人工评审仍为 `pending`。

## 7. P2-05 持久化检查点

交接记录使用独立数据库列，不保存自由 JSON、聊天摘要或用户原文。`proposalExpiresAt` 固定约束授权与执行窗口，`expiresAt` 单独约束数据保留；授权后最长保留 30 天。拒绝、提议过期和安全中断会物理删除记录，完成凭据到期后由统一清理任务删除。

持久化层校验会话属于当前用户，行动与回访引用属于当前会话，公共内容引用存在于审核目录。读取始终同时使用 `userId + id`，账户或会话删除通过外键级联清除交接记录。该层只返回结构化 `authorityChange`，不直接修改当前 Agent；公共 API 与用户可见交接仍未启用。
