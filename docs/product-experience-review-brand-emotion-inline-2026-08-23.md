# BoonZoom 品牌与轻量情绪猜测区评审

## 变更信息

- 变更名称：品牌更名与情绪猜测区轻量化
- 基线版本 / 候选版本：`浮屿` + 页面中央带底板浮层 / `BoonZoom` + 品牌下方纯文字区
- 受影响不变量：`EX-04`、`EX-09`；非回归 `EX-01`–`EX-03`、`EX-05`–`EX-08`、`EX-10`
- 受影响路径：用户控制 / 能力诚实 / 品牌 / 聊天布局
- 预期改善：情绪猜测不再遮挡或挤压聊天；品牌名称统一为 BoonZoom；纠正能力仍可见。
- 可能伤害的体验：猜测提示过轻导致用户忽略其不确定性；纠正入口在小屏幕上难以操作；展开纠正编辑器遮挡对话。
- 保护措施：保留“tata 的猜测”与免责声明；“准确 / 不准确”仍为有边框按钮；展开编辑器只由用户主动触发，取消入口保留。
- 关联 Eval 指标：不改变回复、角色、路由、金标、阈值或 Judge。
