# 鹿禅、tata、飞儿角色与语音分层 v1 迁移说明

日期：2026-08-25

体验版本：`experience-v3` → `experience-v4`

角色注册表版本：`public-agents-2026-08-25.1`

## 目的

将鹿禅、tata 与飞儿从容易混用的称呼和语音配置，迁移为三个独立公开 Agent。此次不改变安全优先级，也不改变行动授权、记忆授权和退出权。

## 公开角色边界

| Agent ID | 公开角色 | 职业定位 | 表达方式 | 默认云端声线 |
| --- | --- | --- | --- | --- |
| `zen_deer` | 鹿禅（鹿灵） | 清简观照者、传统文化向导 | 短句留白；普通低风险回应优先带一个禅宗观照；不以古词堆砌禅意 | `zh-CN-YunjianNeural`，低沉、慢速、`narration-relaxed` |
| `spirit_otter` | tata（水獭） | 温馨体贴的日常陪伴者 | 自然口语；先照顾感受与余力；不讲公案、命理或管家汇报 | `zh-CN-XiaoxiaoNeural`，柔和、稍慢、`gentle/friendly` |
| `bird_courier` | 飞儿（飞鸟信差） | 精明懂事的生活秘书与活动管家 | 清晰利落；先办明确任务；推荐说明理由；保存兴趣和对外动作逐次授权 | `zh-CN-XiaoyiNeural`，清晰、稍快、`serious/cheerful` |

浏览器语音使用相同的性别、速度与音高方向选择本机可用中文声音。安全场景统一降低表演性，直接说明现实信息。

## 兼容策略

- 当前鹿禅界面的新输出统一使用 `zen_deer.*`。
- 历史鹿禅语音标识 `spirit_otter.deep_tide` 与 `spirit_otter.shore_pick` 仅作为只读兼容别名，仍映射到鹿禅，不能改映射为 tata。
- `tata.welcome` 保留为 tata 旧欢迎语音别名。
- 新的 tata 输出只使用 `spirit_otter.warm_companion`、`spirit_otter.caring_clear` 与 `spirit_otter.safety_plain`。
- 新的飞儿输出只使用 `bird_courier.*`。

## 受影响体验不变量

- `EX-04`：角色风格不能凌驾于用户要求直接、暂停或拒绝。
- `EX-05`：三个公开角色严格分离；鹿禅内部灵格仍保持同一角色连续性。
- `EX-07`：安全场景停用公案、哄慰和管家表演。
- `EX-08`：温馨陪伴不得强化依赖。
- `EX-09`：社区、活动目录、语音或记忆能力未连接时必须直说。
- `EX-10`：飞儿保存兴趣、通知、报名、联系和发布分别获得授权。

## 非目标

本迁移现已覆盖角色卡、提示词边界、身份协议、语音包和三 Agent 的内圈对话入口。鹿禅、tata 与飞儿都可由用户点击激活；切换不会自动发送消息，既有回复继续显示其原始角色身份，当前角色会随会话保存。

飞儿虽然已经可以对话并接收用户主动带回的公共内容，但真实社区连接、自动活动推送和长期兴趣档案仍未开放。飞儿不得把一次聊天或一次外圈浏览静默写成兴趣，也不得代替用户报名、联系、发布或通知。

### 2026-08-25 运行时接入检查点

- 会话和消息增加明确的 `activeAgentId` / `agentId`，不再从界面外观猜测说话者。
- 三个入口共用同一私密对话面板，但分别使用自己的欢迎语、占位提示、系统提示词、回复校验和语音包。
- 用户每次点击 Agent 时，该 Agent 会用自己的欢迎声线播放一句短招呼；招呼不写入消息历史、不自动发送内容，重复点击仍由用户控制。
- 高风险场景继续由统一的 `safety_plain` 抢占；角色风格不参与安全表演。
- tata 与飞儿的普通回复分别约束为温馨陪伴和生活秘书，不复用鹿禅的公案、命理或禅意措辞。
- 飞儿当前不会从对话自动生成记忆候选，社区与长期偏好能力保持能力诚实。

后续社区空间统一服从 `docs/three-circle-world-and-community-linkage-v1.md`；三角色同属用户的内圈 Agent 小队，但一对一私密对话不会因此自动互通。

没有修改金标、冻结样本、阈值或 Judge Prompt。
