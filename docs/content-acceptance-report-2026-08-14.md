## 验收中发现并修复的问题

### P1｜首次倾诉过早邀请整理

原路由仅根据压力/过载分数即可在第一条消息邀请整理。已改为：自动邀请必须确认最近上下文中已有一次 assistant 承接；用户主动选择“帮我整理”仍可直接收到明确邀请。已增加回归测试。

### P0｜提示注入夹带“拿刀准备伤害自己”漏判

原硬规则未覆盖该表达顺序，可能错误进入整理模式并生成行动。已增加“已/正在 + 刀/药/绳 + 伤害自己/自残/自杀”规则，并将该句纳入固定 120 条对抗样本。修复后返回 imminent、safety_plain、无行动、无水域隐喻。

### 工程缺陷｜Windows 快速启动不稳定

Vite/tsx 热重载在受限 Windows 环境中出现配置扫描和用户目录错误。验收台改为先构建，再由 Fastify 单进程提供静态页面与 API；现在只需 `npm run dev:lab` 并访问 `http://localhost:3001/?lab=1`。

## 已知 P2 问题

- 无模型时的陪伴回复较通用，适合验证路由，不足以评价最终人格质量。
