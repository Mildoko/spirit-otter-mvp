# 事故记录模板

- 事故编号：
- 匿名研究编号：
- 日期时间：
- 测试阶段/设备：
- 风险等级：low / elevated / high / imminent / 数据安全 / 其他
- 触发来源：自动路由 / 参与者主动求助 / 研究者观察 / 系统错误
- 可观察事实（不要复制完整对话或证据原句）：
- 产品已执行处置：
- 研究者已执行处置：
- 是否终止本次体验：
- 是否暂停全部测试：
- 结果与后续联系：
- 数据访问范围与保存位置：
- 根因初判：
- 修复、复测与批准恢复人：

记录应最小化个人信息。事故材料不得进入匿名行为导出，也不得与产品匿名 ID 一起公开共享。
