# 低信号路由 v1 与表达风格 v2 实施记录

## 基线冻结

- 改造前本机基线（2026-08-18）：类型检查通过；服务端 202 项通过；8 项 Postgres 集成因未配置 `TEST_DATABASE_URL` 跳过。
- 原有冻结集：31 条角色路由、51 条语言响应、120 条安全样本；现有真实模型脚本中的前 20 条保留为旧自动基线，额外样本不计入旧基线回归。
- 低信号与表达验收分开运行：`npm run test:model:low-signal` 与 `npm run test:model:expression`，分别输出独立报告。

## 阶段 A 实施范围

- `RawSignals` 新增表达清晰度与推进准备度，并同步 Zod、DeepSeek 提示和本地可审计规则。
- 新增 `GuidanceStateV1`、安全解析器和纯 reducer；两轮澄清上限、邀请即时有效、拒绝迟滞与不提问边界均持久化。
- 路由优先级固定为风险、明确边界、直接行动请求、已接受切换，再处理低清晰度与一般推进意愿。
- 正式模式在完成轮次事务中写入状态和内部诊断；失败与幂等重放不重复推进。demo 按浏览器会话隔离，reset 清零。
- 本地 fallback 覆盖单词、时间、三选一和暂停脚手架；校验器限制问题、未授权行动与重复邀请。

## 阶段 B 实施范围

- 表达 v2 由 `EXPRESSION_STYLE_V2` 控制；full 默认关闭，demo/lab 默认开启。
- 风格字段统一为口语度、句式节奏和单一表达亮点；高唤醒、高过载、回到深汐及非低风险统一收敛。
- 亮点采用语义适配，不随机抽签；通用冷却 2 轮，比喻 3 轮，警句和干幽默 5 轮。
- 新增水域、日常机械、空间、天气/身体感词族，以及有限警句、干幽默和导师化禁用规则。
- 校验器覆盖同轮多亮点、风险修辞泄漏、无锚点比喻、无证据警句、正式总结和重复填充词。

## 发布门禁

- 自动门禁：类型检查、单元、冻结验收、构建、demo E2E。
- 外部门禁：Postgres 集成与 full E2E 必须使用独立测试库；未运行不得标全绿。
- 表达 full 开关保持关闭，直到真实 DeepSeek 报告完成且人工盲评自然度、角色一致性均达到 4/5，安全边界全部通过。
- fallback 必须在报告中明确标记，不得计作真实模型风格通过。
