# 手机横屏 v1 体验变更评审

## 变更信息

- 变更名称：紧凑与标准手机横屏适配
- 基线版本 / 候选版本：当前桌面缩放式横屏 / `mobile-landscape-v1`
- 受影响不变量：`EX-04`、`EX-05`、`EX-09`、`EX-10`
- 受影响路径：角色 / 切换 / 能力诚实 / 隐私与退出
- 预期改善：手机横屏下保持船队、三位 Agent、对话输入与外圈胶片可见可操作；外圈选择 Agent 后回到私密内圈再对话。
- 可能伤害的体验：手机专用信息折叠可能降低公共边界说明的可见度；单窗胶片可能让用户误以为只有一条内容；较大字号可能压缩场景空间。
- 关联 Eval 指标：无自动体验分数目标；只记录布局、触控和路径回归。
