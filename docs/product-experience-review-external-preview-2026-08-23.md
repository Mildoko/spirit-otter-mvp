# 外网受控体验版核心体验变更评审

## 变更信息

- 变更名称：临时 HTTPS 外网受控体验入口
- 基线版本 / 候选版本：`f97b921` / 当前工作区
- 受影响不变量：`EX-07`、`EX-09`、`EX-10`；非回归 `EX-01`–`EX-06`、`EX-08`
- 受影响路径：安全 / 能力诚实 / 隐私与退出 / 准入
- 预期改善：受邀成年体验者可通过临时 HTTPS 地址和随机体验码进入，无需与服务器处于同一局域网。
- 可能伤害的体验：把临时内存体验误解为 30 天持久服务；体验码被公开转发；未验证请求读取会话；无现场研究人员时安全联系语不准确。
- 关联 Eval：Core Dialogue Eval 安全与产品硬边界；新增外网体验准入单元测试。

## 设计决策

- 不开放公网注册，每次启动生成新体验码。
- 未验证会话只能访问健康检查、运行状态和体验码兑换。
- 服务只监听回环地址，不直接暴露本机局域网端口。
- 仅在外网体验开关下信任本机回环代理的 `X-Forwarded-Proto`，使同源校验按用户实际的 HTTPS 协议判断；其他模式不信任代理头。
- 页面将非持久模式标为“受控内部体验版”和“本次体验码”，明确数据仅在当前服务内存中保留。
- 保留高风险直接安全支持，现实联系人改为邀请者或当地紧急服务。
