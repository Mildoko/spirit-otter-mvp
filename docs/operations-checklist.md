# 局域网试用操作检查表

## 启动前

- [ ] `npm run preflight:full` 全部通过。
- [ ] 当前提交 SHA、页面版本与 `/api/runtime` 版本一致。
- [ ] Postgres 备份已加密，校验值、到期日和操作人已登记。
- [ ] 研究设备已安装本地 CA，浏览器访问 `https://otter.local` 无证书警告。
- [ ] `Secure`、`HttpOnly`、`SameSite` Cookie 已在目标浏览器确认。
- [ ] 现场研究联系人、紧急处置责任人和终止条件已经确认。
- [ ] 只生成本次预试需要的一次性邀请码。

## 启动

1. 启动 Postgres，等待健康检查通过。
2. 运行 `npm run init:full`；不得忽略预检或迁移失败。
3. 启动 API、Web 预览服务和 Caddy。
4. 检查 `/api/health`、`/api/runtime`、邀请码兑换、模型调用和会话恢复。
5. 从局域网外设备确认服务不可访问。

## 停止

1. 停止发放邀请码并等待正在处理的轮次结束。
2. 停止 Caddy、Web 和 API，再停止 Postgres。
3. 运行数据清理并记录各表删除数量；不得记录对话文本。
4. 生成加密备份并登记校验值和保留到期日。

## 故障与回滚

- 页面/API 版本不一致：停止新会话，重新构建并同时重启前后端。
- 模型不可用：正式研究立即暂停，不以规则模拟继续采集。
- 数据库短暂失败：确认会话锁释放和幂等键状态后再允许重试。
- 跨用户数据、删除失败或安全响应失效：立即终止全部测试并建立事故记录。
- 回滚只能使用与数据库迁移兼容的已验收版本；需要恢复数据时遵循 `backup-restore.md`。
