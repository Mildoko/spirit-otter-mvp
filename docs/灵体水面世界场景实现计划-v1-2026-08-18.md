# 灵体水面世界场景纵向切片开发计划 v1

> **历史实现记录，已停止作为当前产品规范。** 水下/水面/上浮/漂浮物不再表示用户状态，水面镜头也不再定义产品信息架构。湖面、小船和星空仅可作为后续三圈世界的视觉素材参考。当前方案见 `docs/three-circle-world-and-community-linkage-v1.md`。

## Summary

首版继续沿用现有 React/Vite 应用，以 **PixiJS v8 + WebGL 的 2.5D 分层场景**实现，不切换 Godot 或 Unity。

交付目标：

- 水平视角下展示水面、小船、背对用户的主角和可交互水獭。
- 点击水獭后展开对话界面。
- 水獭根据交互和回复阶段表现确定性动作。
- 实现流动水面、倒影、涟漪、微粒和轻微视差。
- 通过按钮切换到仰望星空，再返回水面；首版不做星星交互。
- demo/lab 先启用，full 默认关闭并可立即回退。
- 使用原型分层资产验证技术和体验，后续直接替换正式美术。

预计开发周期约 6–8 个工程日。

## Architecture and Interfaces

### 场景结构

```text
React DOM
├─ 设置、提示、输入框和对话抽屉
├─ 无障碍按钮与降级界面
└─ Pixi Canvas
   ├─ HorizonScene
   │  ├─ 星空与远景
   │  ├─ 山脉和地平线
   │  ├─ 远层水面与倒影
   │  ├─ 小船与用户背影
   │  ├─ 远处灵体占位
   │  ├─ 可交互水獭
   │  └─ 前景涟漪与微粒
   └─ SkyScene
      ├─ 星空背景
      ├─ 星云与微粒
      └─ 返回水面控制
```

- React 继续负责业务、输入、对话、设置、情绪面板和无障碍。
- Pixi 只负责世界场景、角色动作、镜头过渡和视觉特效。
- `SceneState` 继续表示对话语义场景，不与镜头方向混用。
- 镜头使用 `horizon | sky` 两个独立容器，通过约 800ms 的抬头、视差和淡入淡出完成切换，不建立 360 度相机。
- `prefers-reduced-motion` 下取消位移，只保留短暂交叉淡入淡出。

### 公开类型

新增可选视觉指令，不改变现有对话请求：

```ts
type VisualActionV1 =
  | "idle"
  | "notice"
  | "approach"
  | "listen"
  | "think"
  | "speak"
  | "invite"
  | "withdraw"
  | "safety_still";

interface VisualCueV1 {
  schemaVersion: 1;
  agentId: string;
  action: VisualActionV1;
  intensity: 1 | 2 | 3;
  durationMs: number;
  ripple: "none" | "soft" | "clear";
  glow: "dim" | "normal" | "warm";
}
```

`ChatTurnResponse` 增加：

```ts
visualCue?: VisualCueV1;
```

新增前端本地状态：

```ts
interface SceneWorldStateV1 {
  view: "horizon" | "sky";
  transition: "idle" | "lifting" | "lowering";
  dialog: "closed" | "open";
  renderer: "loading" | "ready" | "fallback" | "context_lost";
  quality: "high" | "balanced" | "low" | "static";
}
```

- `visualCue` 由服务端根据最终风险、路由和回复确定。
- `listen`、`think` 等请求过程动作可由前端触发；收到响应后必须服从服务端指令。
- elevated/high/imminent 一律输出 `safety_still`，关闭发光增强、幽默化动作和明显涟漪。
- 情绪推测不能直接改变天气、天空颜色或制造暴风雨等戏剧化效果。
- 缺失、非法或未知动作统一降级为 `idle`。

## Implementation Plan

### S0｜基础设施与回退

- 引入 PixiJS v8，建立独立场景根组件和资源清单。
- 增加 `SCENE_WORLD_V1` 开关：demo/lab 默认开启，full 默认关闭。
- 保留现有页面作为静态回退；WebGL 不可用、初始化失败或上下文丢失时，对话仍可正常使用。
- 建立渲染质量分级，依据设备能力、视口尺寸、降运动设置和运行帧率选择效果。
- 在 lab 诊断中显示质量档位、帧率、资源状态、上下文丢失和当前动作，不记录对话原文。

### S1｜原型资产与场景骨架

- 将概念图作为视觉目标，制作临时分层资产：天空、远景、水面、小船与用户、水獭、倒影遮罩、涟漪和微粒。
- 所有资产通过清单加载，固定锚点、尺寸、层级、命中区域和替换规则。
- 建立 16:9 主构图；超宽屏扩展天空和水面，窄屏裁切两侧但保留小船、水獭和交互区域。
- 水獭使用独立透明资产，不把点击区域绑定在整张背景图上。
- 首屏只加载水平场景关键资产；星空镜头资源后台或首次点击时加载。

### S2｜水面与环境表现

水面采用可分级的合成方案：

- 绘制基础水面纹理和低频 UV 扰动。
- 将远景、小船和水獭写入低分辨率倒影纹理，垂直翻转后进行模糊、着色和轻微扭曲。
- 建立涟漪对象池，点击水獭、靠近和说话时在指定锚点生成，不无限创建实例。
- 增加低密度星光、漂浮光点和水面微粒。
- balanced 档降低倒影分辨率和微粒数量；low 档关闭动态倒影；static 档使用静态背景和 CSS 淡入淡出。
- 环境循环保持缓慢、克制，不随每句话闪烁或大幅改变。

### S3｜水獭动作系统

首版动作由状态机控制，不允许模型生成任意动画名称：

```text
idle
→ notice
→ approach
→ listen
→ think
→ speak / invite / safety_still
→ idle
→ withdraw
```

具体触发规则：

- 指针进入或键盘聚焦：`notice`。
- 点击水獭：`approach`，随后展开对话抽屉。
- 用户发送消息：先 `listen`，等待模型期间进入 `think`。
- 普通回复：`speak`；邀请用户推进时允许 `invite`。
- 高风险回复：立即中断其他动作并进入 `safety_still`。
- 用户关闭对话：`withdraw`，结束后回到 `idle`。
- 请求失败或非法视觉指令：平静回到 `idle`，不表现惊慌。
- 新动作到达时可中断旧动作，但同一时刻只允许一个主动作。
- 每个动作由姿态、位移、呼吸、发光、涟漪组合实现；首版使用 Pixi spritesheet/mesh，不引入 Spine。

### S4｜镜头与对话交互

- 默认显示完整水平场景，对话抽屉关闭。
- 点击水獭或对应无障碍按钮后打开对话：
  - 桌面端从右侧展开半透明抽屉。
  - 移动端从底部展开可拖动面板。
- 生成回复期间允许收起抽屉，请求继续；再次打开时恢复当前内容。
- 星空按钮置于场景固定位置，点击后暂时锁定重复操作，执行抬头过渡。
- 星空镜头仅提供待机动画、星云视差和“返回水面”操作，不加入星星点击、星座或记忆系统。
- 镜头状态只保存在当前浏览器会话；新会话默认回到水面。
- Pixi 命中区域同步提供真实 DOM 按钮，支持键盘、屏幕阅读器和触摸操作。

### S5｜集成与内部发布

- 将服务端最终路由映射为 `VisualCueV1`，先完成水獭单角色映射。
- 保持情绪识别、低信号路由、表达风格和安全规则的既有优先级。
- 其他灵体首版只允许作为远景静态占位，不开放点击、对话或角色切换。
- 在 demo/lab 开启场景，保留一键切换旧界面的回退入口。
- 内部成员验证稳定后，再为正式灵体资产、角色交接和星空内容建立独立阶段。

## Test and Acceptance

### 自动测试

- 视觉指令 Schema：未知动作、越界强度、非法时长和缺失字段安全降级。
- 动作状态机：发送、等待、回复、失败、关闭和快速连续操作均只有一个主动作。
- 安全优先级：任何动作都可被 `safety_still` 中断，高风险不出现暖光、邀请或明显涟漪。
- 镜头状态机：切换期间不能重复进入，资源失败可返回水面，降运动设置无大幅位移。
- 质量分级：WebGL 不可用、低性能和上下文丢失均进入可用回退。
- 现有安全、路由、情绪、表达和对话测试不得回退。

### E2E 与视觉回归

覆盖桌面、平板和手机尺寸：

- 首次进入显示水面、小船、用户背影和水獭。
- 点击或键盘激活水獭后正确展开对话。
- 发送消息后依次出现倾听、思考和回应动作。
- 点击星空按钮完成切换并可返回，不影响既有对话。
- 对话面板收起和重新打开后内容与请求状态保持。
- elevated 以上进入静止支持状态。
- 刷新、reset 和新会话恢复正确默认状态。
- Horizon、Sky、对话打开和移动端四组关键截图进入视觉回归。

### 性能门禁

- 桌面高质量目标 60fps，持续场景平均不低于 55fps。
- 移动和平衡档目标 30fps，持续场景平均不低于 28fps。
- 涟漪、微粒和动画对象均有数量上限，长时间运行不持续增加。
- 首屏场景关键压缩资产控制在 4MB 以内，星空和非关键资产延迟加载。
- Canvas 卸载后不残留动画循环、事件监听或声音资源。
- 连续运行 30 分钟无明显内存上涨、上下文崩溃或对话失效。

## Assumptions

- 已上传概念图拥有用于内部原型和衍生资产的授权。
- 首版选择原型资产先行，正式美术可以按同一资产清单直接替换。
- 首版只实现水獭一个可交互灵体。
- 星空首版只有镜头切换和待机画面。
- 对话采用点击灵体后展开的覆盖层，不继续使用固定左右分栏作为主形态。
- 不实现 360 度视角、自由航行、真实 3D 物理、音频、星图记忆、角色交接或多人场景。
- 首版不引入 Spine，不增加数据库迁移，也不将场景状态写入长期用户记忆。
- 当场景能力与对话安全发生冲突时，安全回复和可用的 DOM 对话界面始终优先。
