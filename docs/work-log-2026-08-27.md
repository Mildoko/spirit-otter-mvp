## 今日发现与处理

1. 仅有功能开关不足以保证能力诚实。P2 Capability Manifest 因此增加“开关已开 + 实现已就绪”双条件，避免尚未实现的能力被误报为可用。
2. Agent 交接不需要额外复制私密对话摘要。三个 Agent 已位于同一私密会话，交接对象只保存结构化焦点和不透明内部引用，可显著缩小隐私面。
3. 交接授权窗口与数据保留期必须分离。数据库分别保存 `proposalExpiresAt` 和 `expiresAt`，避免把 30 天审计保留误当成仍可执行的授权。
4. P2 数据表不使用自由 JSON，并增加 Agent、授权、时限、单开放交接和级联删除数据库约束，防止应用层遗漏演变为隐私或授权漏洞。
5. 本机 PostgreSQL 系统服务显示运行，但配置端口没有监听；临时 PostgreSQL 完成初始化后，又被执行环境禁止创建本地 TCP Socket。临时目录已经清理，现有应用数据库未被修改。
