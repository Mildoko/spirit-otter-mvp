# 灵体水面世界场景 v1 自测方案与报告

> **历史测试记录。** 本报告只证明旧水面场景原型在当时的技术状态，不代表当前产品方向或发布验收。当前三圈世界方案见 `docs/three-circle-world-and-community-linkage-v1.md`。

## 1. 目标与范围

验证场景纵向切片在 demo/lab 模式下可体验、可回退且不破坏既有对话和安全能力；确认 full 模式默认保持旧界面。

本轮覆盖：

- Pixi 场景初始化、静态回退与基本性能；
- 水獭激活、对话抽屉、消息发送、收起与恢复；
- 水平/星空镜头切换；
- 服务端视觉指令和安全优先级；
- 桌面与移动端布局、键盘可访问入口；
- 构建、类型检查、单元测试、E2E 和资源预算。

本轮不把正式角色分帧、动态 RenderTexture 倒影、30 分钟设备矩阵稳定性作为发布阻断项；这些仍属于后续精修阶段。

## 2. 测试环境

- 日期：2026-08-18
- 运行模式：demo；full 通过配置测试确认默认关闭
- 浏览器：桌面 Chromium、Pixel 7 模拟尺寸、应用内浏览器 390×844 视觉检查
- 场景基准尺寸：1672×941

## 3. 通过标准

### 3.1 构建与回归

- 根项目生产构建成功；
- 全工作区类型检查无错误；
- 既有单元/验收测试无新增失败；
- demo 场景 E2E 在桌面与移动端均通过。

### 3.2 功能

- demo/lab 默认开启场景，full 默认关闭且可显式覆盖；
- 首次进入显示完整概念场景，对话默认关闭；
- 点击或键盘激活水獭可打开对话；
- 发送期间进入 listen/think，收到回复后执行服务端视觉指令；
- 对话收起后状态保留；
- 星空镜头可进入并返回；
- elevated/high/imminent 均输出 safety_still，且无明显涟漪和暖光。

### 3.3 降级与可访问性

- WebGL 不可用或上下文丢失时显示静态场景，对话仍可操作；
- 水獭、星空、关闭抽屉均存在真实 DOM 按钮和可读名称；
- 移动端输入框与关闭按钮不被遮挡；
- reduced-motion 下不依赖大幅镜头位移完成状态表达。

### 3.4 性能与资源

- 桌面实测目标 55 fps 以上；
- 移动/低质量档功能可用；
- 首屏场景关键图片小于 4 MB；
- 短时运行中帧率、DOM/Canvas 数量和场景状态无持续异常增长。

## 5. 执行结果

### 5.1 自动化结果

- `npm run typecheck`：shared、server、web 全部通过；
- `npm run build`：生产构建通过；
- `npm test`：299 项通过，8 项需要完整数据库环境的集成测试按现有条件跳过；
- `npm run test:e2e:demo`：桌面 3 项、移动端 3 项通过；full 专用流程在 demo 套件中按配置跳过；
- E2E 已使用“聚焦水獭按钮后按 Enter”验证真实键盘激活，不只覆盖鼠标点击。

### 5.2 视觉与交互结果

- 桌面水面场景构图完整，未发现棋盘蒙版、模糊椭圆、图层比例异常或横向溢出；
- 桌面对话抽屉打开后，小船和主要场景仍保留可视空间；
- 星空镜头切换后返回按钮可见，可返回水面；
- 390×844 下抽屉边界为 `left 10 / right 380 / top 260 / bottom 834`，未超出 390×844 视口；
- 移动端输入框边界为 `left 29 / right 361 / top 724 / bottom 798`，软键盘未弹出时完整可见；
- 页面横向滚动宽度为 390，与视口一致；
- 水獭、星空和关闭抽屉均为真实 DOM 按钮并具有可读名称。

### 5.3 性能与稳定性结果

- 首屏实际使用的概念图与涟漪图合计 2,450,742 字节，即 2.34 MiB；
- 桌面质量档为 high，观察值为 58–60 fps；
- 390×844 自动进入 low 档，观察值约 58 fps；
- 45 秒内在 0/15/30/45 秒采样，均保持 `ready · high · 60fps · idle`；
- 四次采样均只有 1 个 Canvas 和 1 个场景实例，控制台无 error 级日志。

### 5.4 自测结论

**内部 demo/lab 纵向切片自测通过，可以交付内部体验。**

正式 full 发布仍为条件性未通过，需补齐真实设备、完整数据库环境、WebGL 上下文主动丢失以及 30 分钟稳定性测试。

## 6. 已知限制与后续测试

- 正式水獭动作需要干净的角色分层或 spritesheet；当前以受控光环和涟漪表达动作；
- 当前保留原图内烘焙倒影，尚未验证动态 RenderTexture 倒影性能；
- 需要在至少一台真实中端 Android 和一台 iPhone 上做触摸、软键盘和长时运行测试；
- 正式发布前仍需执行 30 分钟稳定性测试和截图基线评审。
