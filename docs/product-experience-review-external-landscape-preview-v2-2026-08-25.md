# 外网限量横屏体验版 v2 核心体验评审

## 变更信息

- 变更名称：DeepSeek 真实模型门禁、限量外网入口与全流程强制横屏
- 基线版本 / 候选版本：`3cc4cf4` / 当前工作区
- 受影响不变量：`EX-04`、`EX-05`、`EX-07`、`EX-09`、`EX-10`
- 受影响路径：用户控制 / 安全 / 角色 / 能力诚实 / 隐私与退出 / 外网准入
- 预期改善：受邀体验者在外网使用当前三 Agent 与内外圈版本；真实模型不可用时不开放网址；所有场景保持设计要求的横屏构图。
- 可能伤害的体验：竖屏用户被阻断；自动旋转失败造成困惑；体验码被转发；DeepSeek 失败导致整场无法启动；临时内存被误解为持久保存。
- 关联 Eval：外网环境校验、准入容量、横屏门禁、Core Dialogue 安全与角色回归；主观阻断感保留人工评审。

## 设计保护措施

- 外网模式只允许 DeepSeek 官方 HTTPS 地址、已配置密钥与已支持的 v4 模型；启动前用无用户数据样本探测。
- 探测失败即停止，不降级为规则模拟，保护 `EX-09` 能力诚实。
- API Key 只由服务端读取，不进入浏览器、日志或 Git。
- 每次启动生成随机体验码，默认最多 20 个隔离浏览器会话，可进一步降低。
- 未授权会话不能读取或写入体验数据；服务关闭后内存数据清空。
- 竖屏门禁没有“继续使用”绕过，但保留关闭网页和浏览器的退出权；不能自动锁定时给出明确手动操作提示。
- 不修改角色 Prompt、Router、安全响应、行动、回访、金标、阈值或 Judge。
