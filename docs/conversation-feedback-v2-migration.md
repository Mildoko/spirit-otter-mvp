# tata 对话循环修复与结束反馈 v2 迁移说明

## 版本范围

- Experience Constitution：继续使用 `experience-v2`
- GuidanceState：继续使用 v4；片段结束改用定向重置，保留长期偏好、已确认行动、回访和“不提问”边界
- Event：`event-v3` → `event-v4`
- 反馈接口：新增 `ConversationFeedbackV2`；`HealingSessionFeedbackV1` 兼容一个版本
- 受影响不变量：`EX-01`、`EX-03`、`EX-04`、`EX-05`、`EX-07`、`EX-09`、`EX-10`、`EX-11`、`EX-12`

## 用户体验变化

- 正式体验和外网 Demo 不再展示“tata 的猜测”、逐轮准确/不准确按钮、浮动情绪文字和对应设置项；内部情绪识别仍用于安全、回复风格、场景和水獭表情。
- 用户主动结束聊天时，可以选择“有帮助”或“没帮到”，详细原因、理解程度和离开前变化全部可选，也可以直接跳过反馈。
- 用户明确询问方法时直接回答；接受“缩小范围”后立即聚焦；指出重复、说空、没推进或没有换题后，下一轮必须更换策略。

## 接口与数据

- 打开结束面板返回当前 `segmentId`；提交反馈必须携带该 ID。
- 同一片段的相同提交幂等成功；片段已结束、ID 不匹配或同一片段尝试改写反馈时返回 `STALE_FEEDBACK_SEGMENT`。
- `event-v4` 只记录反馈枚举、片段 ID、反馈来源、反馈版本，以及用于汇总的响应来源和策略，不记录对话正文或洞察正文；数据库不新增表，只迁移行为事件默认版本。
- Demo 反馈只保存在当前体验服务的浏览器会话内存并进入个人数据导出；服务关闭后清空，不提供跨用户汇总导出。
- 旧 `/emotion-corrections` 接口继续兼容旧客户端，但新版主界面不再调用，其数据不进入新版反馈指标。

## 指标与发布边界

- 未反馈单独记录为 `skipped`，不能当作默认满意。
- 点赞率是用户报告的总体体验信号，不能单独证明疗愈有效，也不直接写入长期记忆、训练模型或改变下一轮回复。
- 主观体验评审完成前发布状态保持 `pending`；现有冻结安全金标、阈值和 Judge 未因本次实现修改。
