# P0 可信能力与研究门槛体验评审

## 变更信息

- 变更名称：Capability Manifest、隐私 AI 追踪、三人盲评与 50 段反馈门槛
- 基线版本 / 候选版本：当前工作区变更前 / 当前工作区候选
- 受影响不变量：`EX-05`、`EX-09`、`EX-10`
- 受影响路径：能力说明 / 隐私 / 人工评审 / 扩大体验决策
- 预期改善：客户端不再自行猜测能力；模型故障可在不采集正文的前提下定位；自动测试和少量反馈不能越过真实研究门槛。
- 可能伤害的体验：能力清单配置错误造成入口误开或误关；追踪意外携带内容；研究状态被误读为疗效证明。
- 关联 Eval 指标：不修改既有金标、冻结样本、阈值或 Judge；新增门槛只落实已冻结的真实用户反馈口径。

## 人工对照评审

本变更不修改角色回复、切换、行动、回访文案或 Prompt，因此不把未测量的主观体验自动判为通过。能力诚实性通过运行时契约审查；真实疗愈体验仍保持 `pending`，必须由三名评审者盲评和至少 50 个自愿完整片段反馈完成。

| 维度 | 结果 | 证据 |
| --- | --- | --- |
| 能力边界是否诚实 | 自动契约通过 | Manifest 明确 community.write 与 external_action 不可用 |
| 隐私边界是否诚实 | 自动契约通过 | Trace 属性白名单；关闭资源自动探测和媒体上传 |
| 用户控制是否保持 | 全量与 Experience 回归通过 | Manifest 标记需要明确授权；没有新增外部动作 |
| 主观体验是否改善 | `pending` | 不由基础设施或自动分数代替用户判断 |
