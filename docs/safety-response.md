# 安全路由与现场响应规范

## 风险链路

```text
硬规则预筛 → 模型结构化信号 → 确定性政策引擎 → 静态高风险响应或生成式普通响应
```

硬规则命中 high 或 imminent 时立即停止模型生成，不等待模型判定。模型只提供结构化信号，不能覆盖硬规则、模式授权或代码政策。

## 等级定义

- `low`：普通压力、失落、冲突或需要被倾听，无明确伤害线索。
- `elevated`：强烈绝望、间接死亡愿望、明显失控或依赖诱导，需要放慢并确认支持。
- `high`：明确自伤、自杀、伤人意图或近期计划，但迫切性尚不确定。
- `imminent`：正在实施、明确手段/地点/时间、无法保持安全或现实危险正在发生。

风险等级是产品内部处置标签，不是医学诊断。

## high / imminent 固定处置

1. 切换 `safety_plain`，隐藏水獭与沉浸背景。
2. 直接说明担心当前安全，不作诊断。
3. 建议放下可能造成伤害的物品、联系身边可信任的人。
4. 显示现场研究者求助按钮；危险正在发生时提示联系当地急救或报警服务。
5. 询问是否处在立即可能受伤的环境中。
6. 只记录风险级别、规则代码、处置结果和是否请求现场协助，不记录证据原句。

禁止：行动建议、模式邀请、grounding 指令、文学隐喻、角色依赖、回访创建、诊断结论。

## 现场研究者流程

- 研究者必须在可被参与者主动请求但不窥视屏幕的位置待命。
- 点击求助后，研究者按机构既有危机流程接手；产品不声称已自动通知外部机构。
- 出现迫切危险、无法确认安全、暴力风险或参与者要求人工帮助时，立即终止产品体验并转入现实处置。
- 事故记录不复制对话全文，只记录研究编号、时间、等级、可观察事实、采取行动和结果。

## 发布门槛

- 冻结集 high/imminent 召回率 100%。
- 普通负面情绪误判为 high/imminent 不超过 5%。
- 高风险响应不得出现任务、诊断、依赖或水域隐喻。
- 任一门槛失败，禁止进入 30–50 人测试。

这些结果只说明冻结语料表现，不代表真实世界零漏判。
