# 预约式现场测试操作手册

## 适用范围

30–50 名通过一次性邀请码进入、产品内自我声明满 18 岁的参与者。每人两次现场体验，间隔 24–72 小时。研究设备由组织者管理并预装局域网本地 CA；不得在参与者个人设备安装私有根证书。

## 测试前

- 完成 120 条安全回归、核心 E2E、级联删除和恢复演练。
- 先完成五人内部预试，阻塞性问题清零。
- 检查 HTTPS、数据库、模型出站和 `/api/health`。
- 确认现场研究联系人、紧急处置责任人和终止测试条件。
- 生成一次性邀请码并单独保存；研究编号与真实身份映射由研究者在产品外隔离保管。

## 第一次体验

1. 研究者解释 AI、非医疗、云端模型处理和可随时退出/删除。
2. 参与者自行完成四项同意和邀请码兑换。
3. 独立完成一次倾诉；是否进入整理模式由参与者决定。
4. 若确认行动，只在参与者主动选择时创建 24–72 小时后的站内回访。
5. 记录流程是否完成，不在产品内采集评分。

## 第二次体验

1. 使用同一匿名会话重新进入，确认 AI 身份提醒出现。
2. 检查到期且未关闭的回访是否出现。
3. 参与者可继续、完成、搁置、关闭或删除，不要求解释。
4. 体验结束后可导出或删除自己的数据。

## 立即终止条件

- 任何安全发布门槛失效或出现跨用户数据暴露。
- 产品生成鼓励伤害、诊断、依赖操纵或阻碍退出的内容。
- 迫切现实危险、参与者要求停止、设备或网络无法保障隐私。
- 数据删除或会话隔离失效。

## 决策指标

- 首次核心流程完成率 ≥ 90%。
- 模式邀请后接受或主动进入整理 ≥ 50%。
- 进入整理者的行动确认率 ≥ 60%。
- 第二次预约中已确认行动完成率 ≥ 30%。
- 模式邀请后即时退出率 < 25%。
- 到期回访正确展示率 ≥ 95%。

安全门槛全部通过且至少五项行为指标中的四项达标，才进入下一阶段。下一阶段必须增加主观体验研究，当前行为数据不能代表“被理解程度”。
